Accessibility

Updated November 27, 2026. Project information can be read in the project register and a text list alongside the overview map. Map pins have descriptive labels, keyboard focus and Enter activation. Escape closes popups and project details. Search results announce their updated counts.

Checks and limitations

We tested a fresh private desktop browser and a 390px mobile viewport with Lighthouse and axe. Tested states include first-visit setup, the filtered map and list, Los Gatos Lodge participation details and the Scofield source disagreement. All five tested states scored 100/100 in Lighthouse accessibility, and axe reported zero violations for the selected WCAG 2 A/AA and 2.1 A/AA rules and best-practice checks. The map audit includes its filters and matching list in view. These scores do not certify the whole site or every possible scroll position.

Automated checks cover only the tested states. VoiceOver testing on Mac and iPhone and NVDA testing on Windows remain pending. Third-party city documents, video players and meeting platforms have their own accessibility limitations. Original records may be available only as PDFs or in one language.

Using the dashboard

Use Tab and Shift+Tab to move between controls. Use the map list to open projects without navigating the map. The glossary opens short definitions with links to fuller explanations. Status and participation interface text supports the language selector, while source documents retain their original language.

Use “Report an error” in any project to describe inaccessible or incorrect project information. Include what you were trying to do and the browser or assistive technology you used. For data coverage and source-check limitations, read the coverage page.
